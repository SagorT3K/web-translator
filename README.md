# Web Translator

A free, client-side web translator. Open `index.html` in any browser — no server, no API key required.

## Features

- Translate between 109 languages with auto-detection
- Long-text support (automatic chunking)
- Swap languages, copy to clipboard, text-to-speech
- `Ctrl+Enter` to translate

## How it works

Uses Google's public `translate.googleapis.com` endpoint directly from the browser.
